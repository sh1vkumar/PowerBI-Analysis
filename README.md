# Power BI Dashboard Snapshots

This repository contains automated snapshots of key Power BI dashboards used for business intelligence, performance tracking, and reporting. These snapshots provide historical records and are useful for audits, reviews, and sharing insights externally.

## 📊 Overview

The Power BI dashboards include visualizations and KPIs across various business domains such as:

- Sales Performance
- E-Commerce Dashboard
- SEA Analysis
- Website Efficiency

## 🧰 Technologies Used

- **Power BI Desktop / Service**
- **Power Automate** (for scheduling exports)
- **SharePoint / OneDrive** (optional for storage)
- **Python / PowerShell** (optional for snapshot automation)
- **PDF / PNG / PBIX** formats for saved dashboards
